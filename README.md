# papa-peru

Repo de código de «Ruta del papa León XIV en Perú». Se orquesta desde su meta-repo (carpeta padre; ver `repos.yaml` allí).

Web: https://fertueros.github.io/papa-peru/ — dónde está el papa ahora según la hora de Perú, la próxima
parada, la agenda por días y el clima de cada ciudad. Página estática sin framework (HTML + CSS + JS),
publicada en GitHub Pages por `.github/workflows/pages.yml`. Comandos en [AGENTS.md](AGENTS.md).

Fuentes y atribuciones: agenda oficial de la Sala de Prensa de la Santa Sede; clima de
[Open-Meteo](https://open-meteo.com/) (CC BY 4.0); © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright);
contorno del Perú de [Natural Earth](https://www.naturalearthdata.com/) (dominio público); fotos de
Wikimedia Commons con su autor y licencia en `site/data/agenda.json` y en la propia página.
